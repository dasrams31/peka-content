Antrean topik. Ambil dari atas, bergantian HANDS-ON BUILD / CONCEPT.
Tandai `[x]` + tanggal tayang setelah edisi tayang. Jangan ulang topik

  Verifikasi: docs Anthropic tentang Agent Skills + repo anthropics/skills.

  Verifikasi: docs OpenAI function calling / Anthropic tool use.
- [ ] #04 [CONCEPT] Memori agent - short-term vs long-term, kapan
  memori bikin agent pinter dan kapan bikin agent ngaco.
  Verifikasi: docs LangGraph / Mem0 + satu contoh nyata.
- [ ] #05 [HANDS-ON] Multi-agent workflow - dua agent dengan peran

  Verifikasi: docs CrewAI / LangGraph multi-agent.
