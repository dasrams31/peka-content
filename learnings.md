# Peka AI Content Learnings

Lessons distilled from post performance. Read this file at the START of every
content run and let it guide topic choice, angle, and format.

Format per lesson:
- [YYYY-MM-DD] OBSERVED: <what the numbers showed> / INFERRED: <what to do about it>

## Seed learnings (2026-10-18, launch)

- [2026-10-18] OBSERVED: Account rebranded from MiminNgiler (affiliate) to Peka AI (AI/bansos info). Old audience followed for shopping content; expect low initial relevance. / INFERRED: Early posts should re-establish identity fast — lead with clear value (info AI/bansos), not nostalgia.
- [2026-10-18] OBSERVED: Threads caps posts at 500 chars; long text must be split with reply continuation. / INFERRED: Write the full text first, then split for Threads: part 1 ends with a hook ("lanjut di komentar"), continuation goes as a reply.
- [2026-10-18] OBSERVED: Threads supports exactly 1 hashtag as topic tag. / INFERRED: End every Threads post with exactly one relevant hashtag.
- [2026-10-18] OBSERVED: Copy must not read as AI-generated (user: "jangan keliatan ai narasinya"). / INFERRED: Casual Indonesian social-media voice, strong hook in first 1-2 sentences, short paragraphs, max 1-2 emojis or none. Never "Sebagai AI...", never stiff formal prose.
- [2026-10-18] OBSERVED: Bansos info is high-trust content. / INFERRED: Only publish bansos items verified from official sources (kemensos.go.id, government announcements). Never invent program names, dates, or amounts. When in doubt, run the AI pillar instead.
