Edisi ke-21 SPILL REPO balik lagi, kali ini giliran Antigravity. Google Antigravity itu IDE agentik dari Google yang bisa ngoding bareng kamu, dan biar dia makin jago, kamu perlu ngasih dia skill yang bener. Edisi ini ada 5 repo GitHub berisi skill siap pakai, dari plugin desain software buatan Google sampai kumpulan aturan kustom buat Antigravity. Semua repo di bawah ini masih segar, belum pernah tayang di edisi SPILL sebelumnya, dan semuanya bisa langsung kamu pasang.

1. google/elephant-goldfish-model

google/elephant-goldfish-model

Plugin open source dari Google buat asisten AI, cara kerjanya dibagi dua peran. Elephant nyimpen konteks proyek kamu dan nyusun draf spesifikasi, Goldfish jadi reviewer yang baca draf itu tanpa tahu percakapan sebelumnya, jadi asumsi yang kelewat dan blind spot langsung ketahuan. Kamu yang putusin trade-off arsitektur dan setujuin spesifikasi sebelum mulai ngoding. Ada workflow draft dan design-review bawaan buat spesifikasi software, plus laporan bootstrap dan drift buat codebase. Buat Antigravity, ini bikin agent kamu mikir dulu sebelum nulis kode, bukan langsung tancap gas. Cocok buat kamu yang sering nyesel karena spesifikasi nggak dipikir mateng sebelum agent mulai ngoding.

SPEK: 16.969 star, bahasa utama Python, lisensi Apache-2.0, terakhir update 2026-11-10.

2. gamedev-skills/awesome-gamedev-agent-skills

gamedev-skills/awesome-gamedev-agent-skills

Kumpulan 77 skill game-dev buat AI coding agent, dari Godot, Unity, Unreal, sampai Roblox dan three.js. Semua skill ditulis dalam format SKILL.md yang portabel, jadi bisa dipakai di banyak agent coding. Ada router yang otomatis milihin skill yang pas sesuai engine dan tugas kamu. Sekali pasang, agent kamu langsung tahu cara kerja engine yang kamu pakai tanpa kamu jelasin panjang lebar. Buat Antigravity, ini bikin agent kamu nggak asal tebak pas disuruh bikin game. Cocok buat kamu yang bikin game dan mau agent kamu paham engine yang kamu pakai.

SPEK: 8.123 star, bahasa utama Python, lisensi Apache-2.0, terakhir update 2026-11-10.

3. evanca/flutter-ai-rules

evanca/flutter-ai-rules

Kumpulan 36 skill Flutter dan Dart yang agent kamu muat sendiri pas dibutuhkan, semuanya bersumber dari dokumentasi resmi. Skill ini bentuknya folder berisi SKILL.md, jadi agent baca deskripsinya, lalu narik panduannya pas tugas kamu cocok, misal panduan Firebase Auth pas kamu nyentuh login. Kamu nggak perlu tempel apa-apa ke file rules atau ingat-ingat tag dokumen. Sekali pasang, panduan Riverpod muncul pas kamu pegang provider, dan panduan auth muncul pas kamu pegang login. Buat Antigravity, ini bikin agent kamu ngoding Flutter pakai cara resmi, bukan karangan. Ini repo paling kepakai di edisi ini, apalagi kalau kamu ngoding Flutter tiap hari. Cocok buat kamu yang ngoding Flutter atau Dart di Antigravity dan mau agent kamu ikut panduan resmi.

SPEK: 669 star, bahasa utama Shell, lisensi MIT, terakhir update 2026-11-10.

4. kinopeee/windsurf-antigravity-rules

kinopeee/windsurf-antigravity-rules

Kumpulan aturan kustom buat Windsurf dan Antigravity, sekarang udah versi 5. Aturannya adaptasi dari cursorrules yang udah teruji, dipindah ke format Cascade dan Antigravity. Cara pakainya gampang, taruh file .windsurfrules di root proyek, atau tempel isinya lewat pengaturan workspace AI Rules. Aturannya ngatur gaya dan standar kerja agent biar konsisten di tiap proyek. Buat Antigravity, ini cara paling simpel buat ngasih kepribadian kerja ke agent kamu. Cocok buat kamu yang mau agent Antigravity kamu kerja dengan aturan yang konsisten di semua proyek.

SPEK: 358 star, tanpa bahasa utama terdeteksi, lisensi MIT, terakhir update 2026-09-23.

5. krishnakanthb13/everything-antigravity

krishnakanthb13/everything-antigravity

Repo pusat buat ekosistem Antigravity, isinya kumpulan AI Agents, Task Skills, dan Coding Rules yang dirancang buat workflow coding otonom. Semua koleksinya fokus ke satu hal, bikin Antigravity makin jago kerja sendiri tanpa kamu awasin terus. Repo ini cocok jadi titik mulai kalau kamu baru kenal Antigravity dan mau lihat apa aja yang bisa ditambahin. Isinya terus berkembang bareng komunitas, jadi makin lama makin lengkap. Cocok buat kamu yang baru mulai pakai Antigravity dan mau satu tempat buat cari agent, skill, dan rules.

SPEK: 97 star, bahasa utama Python, tanpa lisensi, terakhir update 2026-10-25.
