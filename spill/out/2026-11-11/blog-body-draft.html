Edisi ke-22 SPILL REPO balik lagi, kali ini giliran Claude. Claude Code itu coding agent dari Anthropic yang makin jago kalau dikasih skill yang bener, dan edisi ini ada 5 repo GitHub berisi skill siap pakai, dari skill resmi Obsidian sampai dua skill yang bisa bikin slide presentasi yang cakep. Semua repo di bawah ini masih segar, belum pernah tayang di edisi SPILL sebelumnya, dan semuanya bisa langsung kamu pasang.

1. obsidianmd/obsidian-skills

obsidianmd/obsidian-skills

Skill resmi dari tim Obsidian buat ngajarin agent AI kamu cara pakai Obsidian. Agent kamu diajarin pakai Obsidian CLI dan format terbuka kayak Markdown, Bases, dan JSON Canvas, jadi catatan kamu tetap bisa dibaca di mana aja. Skill ini ngikutin spesifikasi Agent Skills, jadi bisa dipakai di Claude Code, Codex, dan OpenCode. Cara pasangnya gampang, tinggal tambah lewat marketplace plugin atau satu perintah npx skills add. Sekali pasang, agent kamu bisa bantuin ngerapihin vault, nyari catatan, dan ngolah data Obsidian kamu tanpa kamu jelasin struktur foldernya dulu. Cara pakainya: pasang lewat marketplace plugin atau satu perintah di terminal, lalu agent kamu langsung bisa baca dan ngolah vault Obsidian kamu. Ini repo paling kepakai di edisi ini, apalagi kalau catatan kamu udah numpuk di Obsidian. Cocok buat kamu yang nyimpen semua catatan di Obsidian dan mau agent AI kamu bisa kerja langsung di vault kamu.

SPEK: 51.643 star, bahasa utama tanpa bahasa utama terdeteksi, lisensi MIT, terakhir update 2026-11-11.

2. zhayujie/CowAgent

zhayujie/CowAgent

Asisten AI pribadi open source yang bisa merencanain tugas, jalanin tools dan skill, sampai bikin tim multi-agent sendiri. CowAgent punya memori tiga lapis yang nyimpen konteks, catatan harian, dan ingatan inti, jadi makin lama dipakai makin kenal cara kerja kamu. Ada fitur self-evolution yang otomatis nge-review percakapan buat ningkatin skill dan beresin tugas yang belum kelar. Kamu bisa pasang skill sekali klik dari Skill Hub, GitHub, atau ClawHub, atau bikin skill sendiri cuma lewat obrolan. Instalasi tinggal satu baris, dan semuanya bisa jalan lokal, di Docker, atau di server. Cara pakainya: install sekali lewat installer satu baris, buka konsol web-nya, lalu ajak ngobrol dan kasih tugas pertama kamu. Cocok buat kamu yang mau satu asisten AI yang bisa ngerjain banyak hal sekaligus dan makin pinter seiring dipakai.

SPEK: 47.877 star, bahasa utama Python, lisensi MIT, terakhir update 2026-11-11.

3. davila7/claude-code-templates

davila7/claude-code-templates

Katalog open source berisi lebih dari 1.980 komponen buat Claude Code, dari skill, subagent, slash command, hook, MCP server, sampai settings. Semua komponen bisa dicari dan di-preview dulu di aitmpl.com, lengkap dengan file apa aja yang bakal ditulis ke proyek kamu. CLI-nya nulis tiap file ke tempat yang benar dan ngegabungin konfigurasi lama, bukan nimpa begitu aja. Setiap pull request dicek validator plugin Claude Code dan di-scan NVIDIA SkillSpector, jadi kualitas komponennya kejaga. Kamu bisa install interaktif dengan satu perintah npx, tanpa install global dulu. Cara pakainya: jalanin katalognya secara interaktif, pilih komponen yang kamu mau, dan CLI-nya nulis tiap file ke tempat yang benar. Cocok buat kamu yang mau nambahin skill dan komponen ke Claude Code tanpa ribet nyari satu-satu.

SPEK: 33.310 star, bahasa utama Python, lisensi MIT, terakhir update 2026-11-11.

4. zarazhangrui/frontend-slides

zarazhangrui/frontend-slides

Skill buat coding agent yang bisa bikin presentasi HTML yang cakep, dari nol atau dari file PowerPoint yang kamu ubah. Skill ini dibungkus sebagai plugin Claude Code, dan file SKILL.md intinya juga bisa dibaca agent coding lain yang punya akses file dan shell. Bedanya sama skill lain, dia pakai pendekatan show don't tell, jadi dia bikinin preview visual dan kamu tinggal pilih mana yang paling kamu suka, bukan disuruh jelasin selera desain pakai kata-kata. Hasil akhirnya presentasi web yang siap dibuka di browser, lengkap dengan animasi dan tampilan modern. Buat yang bukan desainer, ini cara paling cepat bikin slide yang keliatan profesional. Cara pakainya: pasang plugin-nya di Claude Code, kasih topik atau file PowerPoint kamu, lalu pilih preview visual yang paling kamu suka. Cocok buat kamu yang sering bikin slide dan mau hasilnya keliatan kayak dikerjain desainer, padahal cuma modal satu perintah.

SPEK: 32.215 star, bahasa utama JavaScript, lisensi MIT, terakhir update 2026-11-11.

5. op7418/guizang-ppt-skill

op7418/guizang-ppt-skill

Skill agent AI buat bikin deck slide HTML yang rapi, dengan layout ala majalah editorial dan gaya Swiss yang bersih. Selain slide, skill ini juga bisa bikin gambar pendukung, cover sosial, dan runtime presentasi WebGL yang tetap enteng. Kamu tinggal kasih satu kalimat, agent kamu yang nyusun layout, nulis konten, dan ngatur tampilannya sampai jadi. Semua hasil akhirnya berupa file HTML yang bisa langsung dibuka di browser tanpa install aplikasi presentasi. Lisensinya AGPL-3.0, jadi gratis dipakai dan dimodifikasi selama kamu ikut aturan lisensinya. Cara pakainya: pasang skill-nya sekali, kasih satu kalimat topik, dan agent kamu yang nyusun layout dan konten slide-nya sampai jadi. Cocok buat kamu yang butuh deck presentasi cepat dan rapi buat kerjaan atau konten, tanpa buka aplikasi slide.

SPEK: 29.639 star, bahasa utama HTML, lisensi AGPL-3.0, terakhir update 2026-11-11.
