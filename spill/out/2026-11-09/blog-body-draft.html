Edisi ke-20 SPILL Repo Skill datang dengan lima repo berisi skill siap pakai buat OpenCode. Ada otak kode biar agent paham codebase besar, skill yang meniru cara berpikir seorang ahli, ingatan permanen buat agent, pelacak kerja banyak agent, sampai plugin buat memakai langganan ChatGPT di OpenCode. Semuanya sudah diverifikasi lewat GitHub API pada 9 November 2026, dan link tiap repo ada di bawah subjudulnya masing-masing.

DeusData/codebase-memory-mcp

https://s.peka.ai.id/NYQvjd

Codebase Memory MCP ini ngasih otak soal kode ke agent AI kamu, jadi dia nggak nebak-nebak tiap kali baca repo. Semua kode, dokumen, dan infrastruktur dihubungkan jadi satu graf yang nempel terus, lengkap dengan MCP tools dan integrasi agent. Ada CBM Lens buat ngintip struktur kode, plus fitur change-aware test selection yang milihin test relevan tiap ada perubahan. Buat OpenCode, ini bikin agent kamu paham codebase besar kayak udah lama kerja di sana. Sekali pasang, dia jawab soal kode pakai konteks beneran, bukan cuma dari potongan file. Cara pakainya umum: pasang MCP-nya di OpenCode, terus suruh dia memetakan codebase kamu sebelum mulai ngoding, dan lihat dia menjawab soal kode pakai konteks yang nyambung.

SPEK: 48.401 star, 4.007 fork, bahasa utama C, lisensi MIT, terakhir diperbarui 9 November 2026.

Cocok buat: Kamu yang kerja di codebase besar dan agent kamu sering salah paham soal struktur kode.

alchaincyf/nuwa-skill

https://s.peka.ai.id/t0gRIR

Nuwa Skill ini idenya unik: dia nyuling cara berpikir seseorang jadi skill yang bisa dipakai agent. Bukan cuma nyontek gaya nulis, tapi juga model berpikir, cara ambil keputusan, sampai DNA ekspresi orang itu. Hasilnya agent kamu bisa kerja dengan pola pikir seorang ahli, bukan cuma template umum. Skill ini jalan di banyak agent coding, termasuk OpenCode, dan dibuat dari proyek Nuwa yang lagi ramai. Buat kamu yang pengin agent kamu mikir kayak mentor favoritmu, ini jalannya. Cara pakainya umum: pilih pola pikir yang mau ditiru, pasang skillnya ke OpenCode, terus minta agent bekerja dengan cara berpikir itu di tugasmu.

SPEK: 37.884 star, 4.867 fork, bahasa utama Python, lisensi MIT, terakhir diperbarui 9 November 2026.

Cocok buat: Kamu yang pengin agent kamu meniru cara berpikir seorang ahli, bukan cuma gaya bahasanya.

rohitg00/agentmemory

https://s.peka.ai.id/ak6VDy

AgentMemory ngasih ingatan permanen ke agent coding kamu, biar dia nggak mulai dari nol tiap sesi. Dia nyimpen konteks proyek, keputusan, dan pola kerja kamu, lalu manggil lagi pas dibutuhkan. Klaimnya nomor satu di benchmark dunia nyata buat memori agent coding, jadi bukan sekadar janji. Buat OpenCode, ini bikin agent kamu makin nyambung dari hari ke hari, kayak rekan kerja yang ingat semua proyek lama. Sekali pasang, makin sering dipakai makin paham dia sama caramu kerja. Cara pakainya umum: pasang skillnya ke OpenCode, terus biarkan dia menyimpan konteks tiap sesi dan memanggilnya lagi saat proyek berlanjut.

SPEK: 30.232 star, 2.679 fork, bahasa utama TypeScript, lisensi Apache-2.0, terakhir diperbarui 9 November 2026.

Cocok buat: Kamu yang agentnya sering lupa keputusan proyek dari sesi sebelumnya.

tryatlas/atlas

https://s.peka.ai.id/bny0Vp

Atlas ini kayak Git buat agent AI kamu, tapi khusus buat kerja bareng banyak agent coding sekaligus. Semua perubahan dari tiap agent ketrek di satu tempat, jadi kamu bisa lihat siapa ngubah apa tanpa buka satu-satu. Kamu juga bisa nanya ke Atlas soal riwayat perubahan itu, misal kenapa satu file berubah kemarin. Buat OpenCode, ini bikin kerja paralel beberapa agent tetap rapi dan gampang diaudit. Sekali pasang, kamu nggak perlu lagi nebak-nebak agent mana yang ngerusak kode. Cara pakainya umum: pasang Atlas di repo kamu, jalankan agent-agent kamu seperti biasa, terus cek satu tempat itu buat melihat dan menanyakan semua perubahan.

SPEK: 9.384 star, 361 fork, bahasa utama TypeScript, lisensi Apache-2.0, terakhir diperbarui 9 November 2026.

Cocok buat: Kamu yang jalanin beberapa agent coding sekaligus dan mau semua perubahannya ketrek rapi.

numman-ali/opencode-openai-codex-auth

https://s.peka.ai.id/mbpB4S

Plugin ini nyambungin OpenCode kamu ke langganan ChatGPT Plus atau Pro lewat login OAuth resmi OpenAI. Jadi kamu bisa pakai model Codex buat coding tanpa beli API key terpisah, cukup pakai langganan yang udah ada. Cara resminya bikin koneksinya aman dan tetap sesuai aturan OpenAI. Buat kamu yang udah langganan ChatGPT, ini cara paling hemat buat ngasih otak tambahan ke OpenCode. Pasang pluginnya, login sekali, langsung bisa dipakai. Cara pakainya umum: pasang pluginnya di OpenCode, login sekali pakai akun ChatGPT Plus atau Pro kamu, terus pilih model Codex saat mulai sesi coding.

SPEK: 2.205 star, 152 fork, bahasa utama TypeScript, lisensi tidak tercantum, terakhir diperbarui 4 November 2026.

Cocok buat: Kamu yang langganan ChatGPT Plus atau Pro dan mau memakainya di OpenCode.
